# VaultKey 🔐

VaultKey is a smart hardware password manager built using ESP32.

## Features

- Secure Local Password Storage
- Bluetooth HID Keyboard Emulation
- OLED User Interface
- WiFi Dashboard
- Auto Login
- TOTP Authentication Codes
- Hardware Authentication Layer
- Digital Logic Security Lock
- Encrypted Credential Storage

## Hardware

- ESP32 WROOM32
- OLED 128x64
- CD4017
- CD4081
- Push Buttons
- Buzzer

## Technologies

- Embedded C++
- Arduino IDE
- Bluetooth HID
- WiFi AP
- Digital Logic Design
- Cybersecurity Concepts
