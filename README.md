# VaultKey 🔐

## Smart Hardware Password Manager

VaultKey is a hardware-based password manager designed using ESP32, Bluetooth HID communication, OLED display, WiFi dashboard, and digital logic authentication circuits.

The system securely stores credentials locally and allows users to automatically send usernames and passwords to computers using Bluetooth keyboard emulation.

---

## 🚀 Features

- Secure Local Password Storage
- Bluetooth HID Keyboard Emulation
- Username Sender
- Password Sender
- Auto Login Functionality
- TOTP Authentication Codes
- OLED User Interface
- WiFi Dashboard for Credential Management
- Hardware Authentication Layer
- Digital Logic Security Lock
- Encrypted Credential Storage
- Buzzer Feedback System

---

## 🔐 Security Architecture

VaultKey uses a hardware authentication layer based on:

- CD4017 Decade Counter
- CD4081 AND Gate Logic

This hardware lock acts as a digital security mechanism before granting access to the password vault, providing an additional layer of protection beyond software authentication.
